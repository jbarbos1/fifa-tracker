1 register_security(ticker, exchange)

Entry point for adding a new ticker. Creates a Security row (UUID PK) and writes a DataIngestionLog record. All other services require a valid security_id from this step first.

6 ingest_report(security_id, report_type, period_end)

Creates a FinancialReport row keyed by (security_id, report_type, period_end). The returned report.id is the FK anchor for all three statement tables. report_type is '10-K' or '10-Q'.

10–14 parse_statements(report_id, raw_data)

Three session.add() calls in a single transaction — BalanceSheet, IncomeStatement, CashFlowStatement — all FK'd to report_id. GAAP requires 1:1 per filing; a single session.commit() guarantees atomicity.

16 ingest_prices() — scheduler job

Async/scheduled call (dashed amber). bulk_save_objects on PriceHistory, then derives MovingAverage rows for window_days ∈ {20, 50, 200}. Unique constraint (security_id, calc_date, window_days) prevents duplicate windows.

20–25 compute_graham_valuation(security_id, calc_date)

Queries IncomeStatement for 10-year EPS average and BalanceSheet for BVPS. Self-call 23 computes graham_number = √(22.5 × eps_10yr × bvps) and ncav = current_assets − total_liabilities. Persists IntrinsicValue + ValuationRatio.

26–30 run_simulation(mu, sigma, horizon, iterations)

Creates a SimulationRun row, executes numpy GBM or historical bootstrap (self-call 28, dashed amber = compute-heavy), then persists SimulationResult with full percentile distribution as JSON and prob_positive_return.

31–36 add_holding() + watch_security()

add_holding computes cost_basis = shares × purchase_price per lot. watch_security writes a Watchlist row with the user's Graham thresholds (max_pe, min_margin_of_safety) and immediately queries IntrinsicValue to return whether the stock currently passes the screen.

Data types: Mapped[Decimal] everywhere financial

Use Numeric(14,4) for prices and ratios, Numeric(20,0) for balance-sheet dollar amounts, Numeric(10,4) for EPS. Map to Python Decimal (not float) to avoid IEEE-754 rounding errors in Graham math.

Service layer pattern

Each service file (services/security.py, services/valuation.py, etc.) takes db.session as a dependency. Routes call services; services call models. Never put session.query() directly in route handlers — this is the wu wei separation that keeps Flask routes thin.
